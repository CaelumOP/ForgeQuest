# Hemo Calisthenics — Foundation level (source for the starter plan)

Playlist: https://www.youtube.com/playlist?list=PLN7P9mLiCVzW8f2PkRIxlReV4PwhcghcB
Read from the on-screen labels and Arabic subtitles on 2026-10-18.

Format: every day starts with stretching (follow the video) + Jumping Jacks 10 reps × 5 sets.
Each block is a circuit: 1 set of each exercise in order, then repeat. 3–4 rounds.
Rest between sets/rounds is open ("as your fitness allows"). Doing fewer reps than written is fine; the number is the target.
Week: Day1, Day2, Day3, Rest, Day4, Day5, Rest. Repeat the week until it's easy, then move to the Beginner level
